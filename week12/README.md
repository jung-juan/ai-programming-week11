# 12주차 — 어느 반이 더 잘했습니까?

성적 CSV를 정제하고 반별 통계를 내서, 「어느 반이 더 잘했는가」에 조건을 붙여 답한다.

## 데이터

- **출처**: 12주차 실습 수업에서 배포한 `scores_2026.csv` (실습용 성적 데이터, UTF-8)
- **행 수**: 원본 114행 → 정제 후 100행
  - 점수 빈 칸 6행 삭제 → 108행
  - 완전히 같은 중복 행 4행 삭제 → 104행
  - 반 · 과목 앞뒤 공백 제거 (행 수 변화 없음) → 104행
  - 점수 0~100 범위 밖 4행 삭제 (999점 3행, -5점 1행) → 100행

### 열 설명

| 열 | 뜻 |
|---|---|
| 학번 | 학생 번호 |
| 이름 | 학생 이름 |
| 반 | 1반 또는 2반 |
| 과목 | 수학 · 영어 · 프로그래밍 |
| 점수 | 과목 시험 점수 (0~100 정수, 단위: 점) |

## 빈 칸 처리

점수가 비어 있는 행은 **지웠다.**
빈 칸을 0점이나 평균으로 채우면 시험을 보지 않은 학생에게 점수를 만들어 주는 것이 되어 반 평균이 달라진다.
있지도 않은 점수를 지어내지 않으려고 지우는 쪽을 골랐다.

## 파일

- `analysis.py` — 정제 함수 `정제(df)`, 반별 통계 함수 `반별평균(df)`
- `test_analysis.py` — pytest 테스트 4개 (정제 후 100행 · 반은 두 종류 · 그룹 합 = 전체 합 · mini.csv 1반 평균 80.0)

## 실행

```
py analysis.py
py -m pytest -q
```

## 결론

반 전체 평균으로 보면 1반(78.24)이 2반(71.44)보다 6.80점 높지만,
과목별로 나눠 보면 수학 · 영어 · 프로그래밍 세 과목 모두 2반이 더 높다.
1반은 점수가 잘 나오는 프로그래밍에 30명, 2반은 점수가 낮은 수학에 30명이 몰려 있어서 생긴 차이다.
